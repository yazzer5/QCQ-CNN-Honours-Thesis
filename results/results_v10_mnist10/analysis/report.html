MNIST 10-class grid (v10)

4 models × 5 seeds, softmax cross-entropy loss (amended from BCE before the grid ran — see docs/AMENDMENT_2026-08-13_loss.md). Multiclass-padded parameter budget: M1 1640 / M2 1646 / M3 1649 / M4 1643 (spread 0.55%). Not directly comparable in parameter count to the binary grids (v6–v9), which used 1604/1610/1600/1594.
Data provenance: raw per-run result_M*.json files were not included in the upload that added this grid to the repo. The table and figures below come from the fallback constants embedded in code/v10_mnist10/scripts/plot_v10_results.py (dated 2026-08-13), which match logs/MNIST_LOG.md §4b. See results_v10_mnist10/summary_v10.json.

Headline findings

  • M2 − M1 = +0.33 pp, p = 0.94, MDE = 16.08 pp — far underpowered relative to the binary grids (MDE 1.4–2.8 pp). Per-seed differences swing from −11.60 pp to +13.05 pp with no consistent sign.
  • QNN-head models are highly seed-unstable at 10 classes (12–15 pp spread) vs classical-head models (5–6 pp). This instability, not the M2−M1 sign, is the primary finding of this grid.
  • Classical head beats QNN head by 11.4 pp (Welch p = 2.2×10⁻⁵). M3 − M4 = −0.45 pp, MDE = 1.38 pp — the quantum front-end contributes nothing detectable at this power level.
  • The +6.4 pp diagnostic that motivated running this grid was a single seed (seed 42 only) and sits well inside the ±13 pp range observed once all five seeds were run — very likely noise, not signal.
